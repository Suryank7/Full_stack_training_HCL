A day-wise collection of Java programs developed during training, covering core Java concepts, object-oriented programming, abstraction, interfaces, and collections.

## Approach

- Organize programs by training day for easy tracking and revision.
- Keep related classes together and create additional files as needed.
- Practice concepts through small, independent Java programs.
- Use IntelliJ IDEA for development and compilation.

## Key Decisions

- **Day-wise organization:** Each day's work stays in its own package or directory.
- **Naming conventions:** Use lowercase package names and PascalCase class names.
- **Source and output separation:** Keep `.java` files in `src` and compiled `.class` files in `out`.
- **Version control:** Exclude generated files and IDE-specific files using `.gitignore`.
- **Incremental learning:** Update this README as new days and concepts are completed.
